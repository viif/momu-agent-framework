# Markdown 总结技能

按要求总结 Markdown 文档。

## 输入参数
$ARGUMENTS

## 执行步骤
1. 先确认文档主题、目标读者与期望输出形式。
2. 若任务涉及本地文件，先使用可用的文件读取工具查看内容。
3. 识别标题层级、关键段落、列表与代码块。
4. 提炼核心观点、重要行动项与可复用信息。
5. 根据内容长度输出简短摘要、分节总结或要点清单。

## 输出要求
- 使用简洁中文
- 优先保留原文结构脉络
- 明确区分结论、要点与待办
